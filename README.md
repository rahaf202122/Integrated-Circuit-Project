# Integrated Circuit Project

## Project Description

This repository contains a university project for the **Integrated Circuit (IC)** course.

The project focuses on circuit design, simulation, and analysis of integrated circuit concepts.

## Project Contents

* Circuit designs and schematics
* Simulation files and results
* Project documentation and reports

## Course

**Integrated Circuit (IC)**

The project was developed and simulated using the required tools and software for the course.
